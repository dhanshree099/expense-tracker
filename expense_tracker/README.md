# Expense Tracker

A web-based Expense Tracker application built using Node.js, Express.js, MongoDB, and EJS.

## Features

- User signup and login
- Add expenses
- View expenses on dashboard
- User authentication
- Organized expense management

## Technologies Used

- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS
- JavaScript
- HTML/CSS

## Project Structure

- `models/` – Database models
- `routes/` – Application routes
- `middleware/` – Authentication middleware
- `views/` – EJS templates
